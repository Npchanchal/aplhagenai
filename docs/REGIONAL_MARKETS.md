# Regional Markets — Alt-Data / GCI Opportunity

Directional market sizing for IntelLens. Vendor reports disagree by 2–4× — use for sequencing, not a financial model.

## Market size by geography

| Region | Size now (~2024–25) | Later (~2030–34) | Character |
|---|---|---|---|
| **Global** | **$5–19B** (mid ~$12B) | $30B–$170B+ (scope-dependent) | Huge definition variance |
| **United States** | **~$4–8B** (~45–70% of global) | Still #1 absolute spend | Largest wallets, densest competition |
| **Europe (EU+UK)** | **~$1–5B** (~10–26%) | Steady | Compliance / ESG / London funds |
| **India** | **~$0.1–0.3B** | **$2.2–4.4B** | Fastest major CAGR (19–56% class) |
| **Japan** | **~$0.3–1B** (~15–20% of APAC) | Slow-steady | High ACV, language moat |
| **China + rest APAC** | **~$1–4B** | Fastest regional growth | China = most APAC $; hard for foreigners |
| **LatAm / MEA / SEA hubs** | Smaller | Selective high-ACV | Brazil, UAE, Singapore as license nodes |

Sources blended: IMARC, Fortune Business Insights, FMI, Grand View (US & India country outlooks).

## Capture & funding for IntelLens

| Market | Capture | What to do |
|---|---|---|
| **India** | Easiest beachhead | Win GCI + vernacular + API here first |
| **United States** | Hardest | Capital / EM India API later — don’t build US-first |
| **Europe / UK** | Medium | Evidence/compliance + Asia coverage to London desks |
| **Japan** | Medium | Expansion after India depth; bilingual JPX product |
| **China / SEA / LatAm / MEA** | Selective | Partner/license API; avoid full rebuild per country early |

## Recommended sequence

1. India GCI + institutional SaaS proof  
2. UK/US quant API for India EM coverage  
3. Japan localization  
4. Selective SEA/MEA licensing
