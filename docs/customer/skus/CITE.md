# CiteAlpha Cite — One Pager

**Bundle:** CiteAlpha Cite · **Legal:** Ocotillo Innovation Private Limited

## What it is

**Citation-as-a-Service** for India equity research: every answer or note fragment must bind to a **primary source** (filing, concall, IR table). Includes **Filing Search** (search, cite-only chat, snapshot, watchlist) and a path to **vernacular factual digests**.

Sellable **without** buying GCI seats — desks that already have a terminal still need cite discipline.

## Who it’s for

| Buyer | Job |
|---|---|
| Research ops | Enforce cite-or-refuse in workflows |
| Sell-side associates | Paste IC footnotes / markdown citations |
| Platform / AI copilots | Embed Cite API into internal chat |

## What’s included

- `GET /api/citations` · `GET /api/citations/{id}` · public `/c/{id}`
- Cite-only research chat (`POST /api/research/chat`) — refuses without evidence
- Bibliographic / markdown / IC footnote formats
- Research search + snapshot + watchlist
- Trust Center citation posture (`/trust`)

## MVP scope

- Outcome- and document-backed citation IDs
- No hallucinated filings in chat
- Usage suitable for interactive Desk + soft API limits

## Non-goals

- Open-ended generative research without sources
- Newsroom / retail tip content
- Cloning a full document management suite
