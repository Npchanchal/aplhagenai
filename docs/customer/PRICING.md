# Pricing & Packages

Illustrative commercial frame for India institutional GTM. Final quotes via order form.

## Plans

### 1. Pilot (evaluation)

| | |
|---|---|
| **Seats** | Up to 5 named users |
| **Universe** | Sensex-30 (current product) |
| **Access** | Workbench UI + read API |
| **Support** | Email, business days |
| **Term** | 30–60 days |
| **Price** | Complimentary (or refundable deposit against Year-1) |

**Exit criteria for paid conversion:** weekly habit among ≥3 analysts; ≥1 published note citing GCI evidence; stakeholder sign-off on data quality for hand-labeled cohort.

---

### 2. Desk (primary ARR)

| | |
|---|---|
| **Seats** | 5–25 (volume discounts above 25) |
| **Universe** | Sensex-30; Nifty expansion roadmap |
| **Access** | Full workbench, alerts, review loop, vernacular blurbs |
| **API** | Soft rate limits suitable for interactive use |
| **Support** | Shared Slack/Teams channel (optional) |
| **Price** | **₹45,000 / seat / year** (illustrative) · annual prepaid |

Includes: SSO roadmap credit, quarterly coverage review, onboarding workshop (2h).

---

### 3. Enterprise API (highest ACV)

| | |
|---|---|
| **Seats** | Workbench seats optional add-on |
| **Delivery** | REST + scheduled export (CSV/Parquet roadmap) |
| **History** | Point-in-time GCI series |
| **EM factor** | Export shape for factor research |
| **SLA** | Contracted uptime & refresh windows |
| **Price** | **₹25–80L / year** (illustrative) by history depth + redistribution rights |

---

### 4. One-Stop Platform (when they want a single vendor)

For desks that ask for a **one-stop solution** — not a Bloomberg replacement, but one contract for the full India guidance-accountability stack.

| | |
|---|---|
| **Seats** | Up to 40 named users |
| **Includes** | Desk + Enterprise API + AlphaHunter import + Wordmap context + badge endpoints |
| **Extras** | Dedicated labeling priority, SSO/VPC scoping, named CSM, QBRs |
| **Universe** | Sensex-30 now + Nifty milestones in SOW |
| **Price** | **₹40L–1.2Cr / year** (illustrative) |

Full pitch, inclusions matrix, and refuse-list: [ONE_STOP.md](ONE_STOP.md).
