# IntelLens GCI — One Pager

## What it is

**Guidance Credibility Index (GCI)** — a 0–100 score of whether Indian listed-company management delivered on quantified guidance. Every score links to period, metric, guided band, actual, label, and source.

## Who it’s for

| Buyer | Job to be done |
|---|---|
| Buy-side / PMS / AIF | Screen chronic guidance misses; size conviction with a track record |
| Sell-side research | Cite auditable guidance-vs-actuals in notes |
| Quant / EM desks | Point-in-time GCI series via API |

## What’s included

- Sensex-30 Guidance Tracker workbench
- Outcome labels: met · exceeded · missed · dropped · pending
- Evidence trail with sources
- Peer rank & sector average
- Alerts, trend, point-in-time history
- REST API + org seats model
- Analyst Accept / Reject review loop
- Vernacular blurb templates (hi / ta / gu / mr / en / ja)
- SEBI-oriented factual disclaimer endpoint

## Why India

Global guidance trackers (Marvin Labs, FinCatch) are strong on US/SEC workflows. Indian NSE/BSE disclosure formats, mixed-language concalls, and local IR tables need a local spine. IntelLens is built for that whitespace.

## What we do **not** ship

- Buy / Hold / Sell recommendations  
- Retail consumer trading app  
- “Trust score” marketing badge as a standalone product (Year-2 option)
