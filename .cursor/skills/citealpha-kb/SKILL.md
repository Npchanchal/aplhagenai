# CiteAlpha Knowledge Base

## When to update

Scoring rules, API routes, UX IA, deploy process, compliance claims, or agent/skill inventory change.

## Steps

1. Edit the matching page under `docs/kb/` (keep concise).
2. Update `docs/kb/README.md` index if adding a page.
3. Update `docs/kb/AGENT_ROUTING.md` if skills/agents change.
4. Point `AGENTS.md` / README Cursor section if inventory shifts.

## Do not

Duplicate long docs — link to `docs/PRODUCT_DEFINITION.md` etc. instead.
